# Mémoire des erreurs

Exemple conceptuel :

> TypeError détectée dans `src/service.py:84`.
> Correction validée le 30 septembre 2026 dans `src/service.py`.
> Vérification : tests réussis.

Lorsqu'une erreur similaire réapparaît, Berkios peut rechercher les entrées
historiques et fournir ces corrections comme contexte au provider.

Les dates sont stockées en ISO 8601 UTC.
