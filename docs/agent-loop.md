# Agent Loop 2.1

Le run n'est plus une simple requête/réponse.

Chaque transition produit un événement structuré. iBook peut donc construire
une interface de type "timeline" :

1. Analyse
2. Proposition
3. Approbation utilisateur
4. Application
5. Vérification
6. Réparation si nécessaire
7. Fin

Le contrôle reste côté utilisateur pour les modifications proposées.
