# Berkios 5.1 — Decision Engine

Transforme le contexte priorisé en décision structurée.

Demande → Agent Context → preuves/contraintes/incertitudes → actions possibles → action retenue → justification → approbation/vérification.

Une décision contient objectif, interprétation, preuves, contraintes, actions, justification et incertitudes.

Le moteur ne contourne pas les permissions.
